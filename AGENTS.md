# Cross-project Agent Conventions

---

## Project documentation

When a project contains PROJECT.md, DESIGN.md, COMPONENTS.md, or
IMPLEMENTATION.md (optionally prefixed with L1-, L2-, L3-, or L4-),
consult PROJECT-DOCS.md in this directory for their intended
roles and interpretation.

Read only existing project documents relevant to the task. Do not
create missing documents or require all four levels unless
explicitly requested. Respect explicit project requirements and
distinguish them from preferences, open decisions, and examples.

---

## General guide for human-readable content

Prefer describing responsibilities positively. State exclusions
explicitly when they clarify genuine ambiguity or enforce meaningful
constraints.

## Markdown documentation style

Consult MD-STYLE.md in this directory for the preferred Markdown
documentation style, when producing technical documentation.

## Code conventions

Consult CODE-STYLE.md in this directory for the preferred code style,
when producing code.
