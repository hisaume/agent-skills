# feature-brief

Presents the high-level intent of an already-planned application change before
implementation. Suited to features, fixes, refactors, and maintenance work in
existing applications; usable on a bounded slice of a new project.

## Usage

`$feature-brief Present the planned session-expiry change before implementation.`

`$feature-brief Explain the scope and expected behaviour of the cache refactor.`

## Output

A proportionate, read-only summary of intended behaviour, scope, affected
components, and observable completion conditions. Minor uncertainties are
identified without reopening planning. Consequential high-level gaps cause an
early exit with a short explanation of what is missing.

## Boundaries

Assumes planning has already occurred. Does not grill the user, design
function-level implementation, seek approval, modify files, or start coding.
It can be used independently of other skills.

## Files

- `SKILL.md` — context review, sufficiency check, presentation, and stopping rules.
