# Edge-Case Register

Canonical register of material failure scenarios and decisions.
Keep IDs stable and never reuse them, including after retirement.
Link executable checks in the normal test suite.

Statuses:

- **Proposed** — awaiting confirmation;
- **Open** — action or verification outstanding;
- **Covered** — full expected behaviour supported by verification;
- **Accepted** — developer-approved risk with a decision reference;
- **Retired** — no longer applicable or consolidated, with history preserved.
