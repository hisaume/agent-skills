# scaffolding-as-context

Uses partial source code as implementation context, distinguishing contractual anchors from advisory suggestions.

## Usage

- `$scaffolding-as-context Consume the scaffold while implementing the search feature.`
- `$scaffolding-as-context Reconcile the scaffold after implementation.`

Call it at the start of an implementation round, or from a relevant documentation file. The skill also supports read-only review.

## Files

- `SKILL.md` — workflow, authority levels, and handoff rules.
